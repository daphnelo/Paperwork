內建說明若已有舊版本，點「說明」後可選擇更新；取消會保留自己修改過的說明。

目前介面：網址打開即進入完整 A4 編輯器。Gemini 是工具列上的「✦ Gemini」小按鈕，
文件分析、論文摘要、分析紀錄與連線設定都從此按鈕開啟。分析期間可繼續編輯，
右下角顯示進度；完成後直接插入目前筆記，或依選擇建立新筆記並存回本機。
此次介面調整不需重啟已在執行的 1.2.0 服務，重新整理網頁即可載入。

啟動與更新
1. 雙擊 start.cmd，保持命令視窗開啟。預設網址為 http://localhost:8000/。
2. 若舊服務仍在執行，先關閉舊命令視窗，再執行 start.cmd 並重新整理網頁。
   請勿同時啟動多份服務操作同一筆記庫。
3. 需要 Python 3.10 或更新版本；這台電腦已安裝，不需另裝 Python 套件。
4. 可執行 python server.py --open。其他程式佔用 8000 時，會尋找 8001–8009。

從筆電的資料夾選取文件
1. 點編輯器上方「✦ Gemini」→「文件分析」→「從本機資料夾選取」。
2. 清單包含子資料夾中的 PDF／DOCX，可搜尋檔名／路徑、篩選類型、
   點左側資料夾或上方路徑瀏覽，再點文件列勾選。
3. 點「加入分析清單」，確認提示詞與模型，再點「開始分析」。
4. 結果直接放進目前筆記或新筆記，並另外保存完整分析報告。
   從 Gemini 的「目前結果」或「分析紀錄」可查看來源報告與下載結果。

選取與讀取規則
- 選資料夾只在瀏覽器列出文件；按「開始分析」才會送出所選文件。
- 一般分析每次最多 5 份、單檔最多 50 MB、合計最多 80 MB，
  合併為一份報告。需要逐篇報告時，請分次提交。
- 同名文件會顯示各自的子資料夾路徑，不會因同名而漏選。
- 支援的瀏覽器可記住上次資料夾，按「重新讀取上次資料夾」重新授權／更新清單。
  記住的是存取參照，並非文件副本。「忘記資料夾」可移除此記錄。
- 無法使用資料夾選擇器時，點「使用相容模式」；相容模式下下次需重選。
- 原始文件不會移動、覆寫或刪除。超過 20,000 個項目時，請選較小的子資料夾。
- Word 支援 DOCX 的正文與表格文字。圖片、公式或版面重要時請轉成 PDF。
  舊版 DOC 請先另存為 DOCX 或 PDF。

論文摘要引入與卡片
1. 點編輯器上方「✦ Gemini」→「論文摘要」，選一篇 PDF，也能從本機資料夾挑選。
2. 選「法學論文」或「其他／社會科學論文」。完整採用提供的兩份摘要提示詞，
   可展開「檢視／微調 Prompt」編輯，不會覆蓋一般分析的自訂提示詞。
3. 選建立新筆記，或插入目前筆記游標處。沒有游標時接續文末。
4. 完成後自動載入 A4 筆記，開啟核心概念清單。可全選／取消全選、查看定義與出處，
   勾選要建立的卡片與歸檔資料夾。
5. 卡片含概念定義、原文重要段落摘錄及出處；文章附卡片徽章，卡片可反向找引用文章。
6. 抽屜可新增跨分類的雙向關聯，搜尋並跳轉卡片；圖譜以虛線顯示關聯。
7. 從歷史記錄可再次開啟摘要／提煉卡片，保留已存在筆記與卡片的編輯內容。
   若原插入筆記已刪除，可使用「改為另建新筆記」。

A4 學術筆記編輯器
- 網站首頁即為提供的 editor.html 樣式與原有編輯功能，使用完整視窗編輯。

  縮放、輸入法處理、復原／重做，以及原有 Word／PDF／Markdown 匯出。

檔案保存位置
分析結果：預設為本工具旁 results，可在「連接與設定」修改。
每次建立獨立資料夾，含 report.md、report.txt、report.html、result.json。
論文 result.json 另保留概念卡片候選內容及載入選項。

編輯後筆記：本工具旁 notebooks/Paperwork筆記庫.html。
每次完整儲存，前一版保留為 Paperwork筆記庫.previous.html。
筆記庫與分析結果輸出位置分開管理。
多個網頁同時修改發生版本衝突時會停止覆寫：先「匯出 HTML」保留本頁內容，
再重新整理並匯入。存檔失敗不會誤報為成功。

Gemini 連線與金鑰
- 點「✦ Gemini」→「連線設定」輸入 API Key 並驗證。
- 未勾選記住金鑰時，Key 僅保留於本機服務記憶體，重啟後需再輸入。
- 勾選後，成功驗證的 Key 存於此瀏覽器 localStorage；重開同一網址可自動連線。
  只在自己的瀏覽器使用；取消勾選或清除連接會刪除記住的 Key。
- 原已存在服務記憶體的 Key 不回傳網頁。如要改成記住，需重新貼上一次。
- Key 不寫入伺服器設定、日誌、筆記庫、分析結果或發佈 ZIP。
- 取得模型清單不代表文件分析權限／配額足夠。分析受專案權限、配額、計費狀態限制。
- 金鑰管理：https://aistudio.google.com/apikey

執行與排錯
- 只監聽 127.0.0.1，未部署至公網。Gemini 分析需要網路與可用 API 專案。
- 分析期間保持服務執行；可重整網頁查詢進度，關閉服務會中斷工作。
- 失敗顯示階段與已知原因，不顯示可能包含金鑰的原始錯誤。
- 輸出過長或截斷不當成成功，請縮小範圍或分章分析。
- 網路逾時可能已在 Google 執行，手動重試可能產生額外用量。
- 分析完成會嘗試刪除 Google Files API 暫存檔；失敗會在歷史記錄提示。
- 存檔失敗請查磁碟空間、路徑與權限，已收到內容會盡可能保留在歷史記錄。
- AI 摘要、原文摘錄與頁碼需核對來源，不會自動確認正確性。
- .local/settings.json 保存一般提示詞、模型與輸出位置；.local/jobs 保存分析歷史。
